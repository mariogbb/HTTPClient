# HTTPClient
Custom implementation of [RFC 9112 - HTTP 1.1](https://www.rfc-editor.org/info/rfc9112/) in Go.

# Resources

- [RFC 3986 STD 66: Uniform Resource Identifier (URI): Generic Syntax](https://www.rfc-editor.org/info/rfc3986)
- [RFC 5234 Augmented BNF Syntax Specifications ABNF](https://www.rfc-editor.org/info/rfc5234/)
- [RFC 5789 PATCH Method for HTTP](https://www.rfc-editor.org/info/rfc5789/) 
- [RFC 9112 HTTP 1.1](https://www.rfc-editor.org/info/rfc9112/)
- [RFC 9110 HTTP Semantics](https://www.rfc-editor.org/info/rfc9110/)

# Constraints

- Excluded TCP protocol implementation  
- Excluded TLS implementation
- Excluded DNS implementation
- Excluded HTTP caching implementation
- HTTP **client** side only
